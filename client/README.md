# MERN SkillGap Studio

An interactive web application designed to help job seekers evaluate their technical skills against target Job Descriptions, calculate real-time match scores, identify missing competencies, and track job applications.

---

## Key Features
- **JWT Authentication:** Secure user registration, login, and protected API routes.
- **Skill Gap Analyzer:** Parses Job Descriptions to calculate skill match percentages and highlight missing technical requirements.
- **Application Tracker:** Full CRUD dashboard allowing users to log, manage, and monitor their active job applications.
- **RESTful API:** Clean modular backend architecture built with Express and MongoDB Mongoose models.

---

## Tech Stack
- **Frontend:** React.js, React Router DOM, Axios, Context API
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, BcryptJS
- **Dev Environment:** Code0 Extension in Visual Studio Code
